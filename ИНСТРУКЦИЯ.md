# Сборка приложения «Невролог» для Windows

## Что нужно установить

1. **Node.js** (версия 18 или новее)
   - Скачать: https://nodejs.org → кнопка «LTS»
   - Установить с настройками по умолчанию

2. **Git** (опционально, только если скачиваете через git)

---

## Пошаговая инструкция

### Шаг 1 — Распакуйте папку проекта

Скопируйте папку `neuro-app` в удобное место, например:
```
C:\Projects\neuro-app\
```

### Шаг 2 — Откройте командную строку в папке проекта

- Зажмите **Shift** и кликните правой кнопкой мыши на папке `neuro-app`
- Выберите **«Открыть окно PowerShell здесь»** (или «Открыть окно командной строки здесь»)

### Шаг 3 — Установите зависимости

```
npm install
```

Подождите, это скачает Electron (~150 МБ). Займёт 1–3 минуты.

### Шаг 4 — Проверьте, что всё работает (запуск без сборки)

```
npm start
```

Должно открыться окно приложения. Закройте его, если всё хорошо.

### Шаг 5 — Соберите установщик .exe

```
npm run build
```

Подождите 2–5 минут. После завершения в папке `dist\` появится файл вида:
```
Невролог Setup 1.0.0.exe
```

Это и есть готовый установщик!

---

## Установка на любой компьютер

Файл `Невролог Setup 1.0.0.exe` можно запустить на любом Windows-компьютере — Node.js там устанавливать **не нужно**. Всё включено в установщик.

После установки на рабочем столе появится ярлык **«Невролог»**.

---

## Возможные проблемы

**npm не найден** — убедитесь что Node.js установлен, закройте и снова откройте командную строку.

**Ошибка при сборке про иконку** — это нестрашно, уберите строки `"icon": "icon.ico"` и `"icon": "icon.png"` из `package.json` и повторите `npm run build`.

**Антивирус блокирует установщик** — это нормально для самоподписанных .exe. Можно добавить в исключения или просто нажать «Всё равно запустить».
