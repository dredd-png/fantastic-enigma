# Невролог — Конструктор истории болезни

Приложение для неврологов, предназначенное для упрощения и ускорения подготовки истории болезни и медицинской документации.

## О проекте

«Невролог» — это инструмент, который помогает врачу структурировать данные неврологического осмотра и быстро формировать готовый текст медицинской документации.

Приложение позволяет последовательно заполнить основные разделы неврологического осмотра и автоматически сформировать структурированный результат.

Проект создаётся с учётом реальных рабочих процессов врачей и ориентирован на уменьшение количества рутинной работы при оформлении документации.

## Текущий статус

Проект находится на ранней стадии разработки.

На данный момент существует рабочая версия приложения, которой уже пользуется практикующий врач в Кыргызстане. Получение обратной связи от реального пользователя позволяет постепенно улучшать интерфейс и функциональность приложения с учётом практических потребностей врача.

## Возможности

Текущая версия включает структурированные разделы для:

- основных жалоб;
- характера головной боли;
- анамнеза;
- сознания;
- исследования черепных нервов (ЧМН I–IV);
- исследования черепных нервов (ЧМН V–XII);
- двигательной системы;
- координации и рефлексов;
- чувствительности и вегетативной системы;
- менингеальных симптомов и высших психических функций;
- предварительного диагноза;
- рекомендаций.

Приложение автоматически собирает введённую информацию в структурированный текст истории болезни.

## Технологии

Проект создан с использованием:

- JavaScript
- HTML
- CSS
- Electron
- Node.js

Electron используется для создания полноценного desktop-приложения на основе существующего веб-интерфейса.

## Сборка

Для запуска проекта необходим Node.js версии 18 или новее.

Установка зависимостей:

```bash
npm install
```

Запуск приложения:

```bash
npm start
```

Создание Windows-установщика:

```bash
npm run build
```

После сборки установщик будет находиться в директории `dist`.

## Планы развития

Текущая версия является первым этапом более масштабной идеи.

В дальнейшем планируется:

- расширять функциональность приложения;
- улучшать существующие инструменты для неврологов;
- учитывать обратную связь от практикующих врачей;
- превратить текущий прототип в полноценное desktop-приложение;
- разработать инструменты для других медицинских специальностей;
- автоматизировать больше повседневных рутинных задач врачей;
- постепенно создать более комплексную программную систему для медицинских работников.

Долгосрочная цель проекта — создать доступный и практичный программный инструмент, который поможет врачам в Кыргызстане тратить меньше времени на рутинную документацию и больше времени на работу с пациентами.

## Конфиденциальность

Проект предназначен для работы с медицинской документацией. Не добавляйте реальные персональные или медицинские данные пациентов в исходный код, репозиторий или публичные примеры.
